movie2music

動画ファイルからAAC音声（.m4a）を抽出するデスクトップアプリケーション

macOS Windows

ダウンロード

macOS — 未リリース Windows — 未リリース

説明

動画ファイル（MP4 / MOV / AVI / MKV / WebM）からAAC形式の音声ファイル（.m4a）を抽出・変換するデスクトップアプリケーションです。 ドラッグ&ドロップまたはファイル選択で動画を追加し、ビットレート・サンプルレート・チャンネル等を指定して変換できます。 変換のデフォルト設定は最高音質です。 ※ 変換処理には別途ffmpeg/ffprobeのインストールが必要です。アプリ起動時に存在チェックを行い、見つからない場合はエラーを表示します。 推奨インストール方法: - macOS: `brew install ffmpeg` - Windows: https://ffmpeg.org/download.html からビルド済みバイナリをダウンロードし、ffmpeg.exe / ffprobe.exe をPATHの通ったフォルダに配置 HE-AAC v1/v2を使用する場合は`libfdk_aac`を含むffmpegビルドが必要です（macOSは `brew tap homebrew-ffmpeg/ffmpeg && brew install homebrew-ffmpeg/ffmpeg/ffmpeg --with-fdk-aac`）。AAC-LCのみ使用する場合は標準ビルドで問題ありません。

主な機能

  • 動画ファイル（MP4 / MOV / AVI / MKV / WebM）からAAC音声（.m4a）を抽出
  • ドラッグ&ドロップ／ファイル選択で複数ファイルを追加可能
  • AAC-LC / HE-AAC v1 / HE-AAC v2 プロファイルを選択可能
  • ビットレート（64〜320kbps）／サンプルレート（44100/48000Hz）／チャンネル（モノラル/ステレオ）を設定可能
  • ffprobeによる動画メタデータ表示（長さ・解像度・映像/音声コーデック）
  • 変換進捗のリアルタイム表示・キャンセル対応
  • 出力先フォルダの選択（デフォルトは入力ファイルと同じフォルダ）
