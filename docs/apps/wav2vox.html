説明

WAV・MP3・M4A・AAC・OGG・FLACなどの音声ファイルを、電話システムで広く使われるVOX形式（Dialogic ADPCM、G.711 uLaw/aLaw）に変換するデスクトップアプリケーションです。 サンプルレートは6000Hz / 8000Hzのモノラル出力に対応しています。 ffmpegは不要で、Rust製ライブラリ（symphonia）により内蔵デコードを行います。 変換前にエフェクトチェーン（音量調整・ノーマライズ・クリック除去・ノイズリダクション・コンプレッサー・イコライザー）を適用できます。 ファイル一覧のドラッグ&ドロップ・波形プレビュー・音声再生プレビュー・一括変換（非同期・進捗表示）に対応しています。

主な機能

  • 対応入力フォーマット：WAV、MP3、M4A、AAC、OGG、FLAC
  • 出力フォーマット：Dialogic ADPCM (.vox)、G.711 uLaw (.vox)、G.711 aLaw (.vox)
  • サンプルレート：6000 Hz / 8000 Hz（モノラル固定）
  • ffmpeg不要（symphoniaによる内蔵デコード）
  • ドラッグ&ドロップでファイル追加・一括変換（非同期・進捗表示）
  • 波形プレビュー（Canvas描画）・音声再生プレビュー
  • エフェクトチェーン：音量調整 / ノーマライズ / クリック・ポップ除去 / ノイズリダクション / コンプレッサー / イコライザー
